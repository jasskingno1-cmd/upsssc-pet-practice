# UPSSSC PET Practice PWA
This is a browser-based installable PWA prototype. Pattern reference: 100 questions, 100 marks, 120 minutes, -0.25 for wrong answers. Source: UPSSSC PET 2025 syllabus appendix https://doc.sarkariresults.org.in/UPSSSC_PET_New_Syllabus_2025.pdf

## Important limitations
- The 10 mock sessions currently rotate a small bilingual practice bank to demonstrate the CBT workflow. They are not 1,000 unique, exam-quality questions; do not treat scores as a reliable predictor.
- The 10 PYQ cards are source links to external archives, not embedded/independently page-verified original papers. Open the exact date/shift and cross-check with the official answer key at https://upsssc.gov.in/. Do not call these embedded verified papers.
- Attempt history is saved locally in the browser only.
- To install as a PWA, host this folder on HTTPS (e.g. GitHub Pages/Netlify) and choose Install app / Add to Home Screen. Opening index.html directly supports practice but not service-worker installation.
Sources: https://prepp.in/upsssc-pet-exam/question-paper ; https://prepp.in/upsssc-pet-exam/question-paper-2025 ; https://www.examsnet.com/exams/govt/upsssc-pet-previous
